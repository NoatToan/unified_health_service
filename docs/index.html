🏃 Unified Health Service — Lịch giải chạy Việt Nam

Đây là bản ghi dữ liệu các giải chạy (marathon, half-marathon, trail…) tại Việt Nam, được thu thập tự động mỗi ngày từ các trang lịch giải chạy công khai, gộp và loại trùng, rồi xuất ra một file JSON duy nhất để ứng dụng di động (hoặc bất kỳ ai) tiêu thụ.

Endpoint JSON (luôn là bản mới nhất):

Mỗi giải chạy trong JSON đều giữ lại sources[] trỏ về trang gốc để đối chiếu.

Cập nhật khi nào?

Một GitHub Action chạy mỗi ngày vào khoảng 03:00 giờ Việt Nam, thử lại các nguồn, và chỉ publish khi mọi thứ hợp lệ. Nếu một nguồn gặp lỗi (đổi giao diện trang…), hệ thống sẽ đánh dấu nguồn đó ok: false trong JSON và giữ nguyên dữ liệu cũ của nguồn đó thay vì làm mất thông tin.

Xem mã nguồn, cách chạy crawler cục bộ và schema đầy đủ trong README trên GitHub.

Trang này được tạo tự động cho mục đích hiển thị dữ liệu công khai. Thông tin về bot thu thập dữ liệu: bot.html.
