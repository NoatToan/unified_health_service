UnifiedHealthRaceBot

This page is the contact/identification target referenced by this crawler's User-Agent string:

UnifiedHealthRaceBot/1.0 (+https://noattoan.github.io/unified_health_service/bot.html)

What this bot does

  • Runs once a day (around 03:00 Vietnam time) via a scheduled GitHub Actions job.
  • Checks and obeys each site's robots.txt before fetching anything.
  • Fetches a small, fixed set of public race-calendar pages (currently: VnExpress's "Lịch giải chạy", the iRace ticket portal's marathon category, Vietnam's Best Marathons' race-info page, and Finishers.com's Vietnam destination page).
  • Also fetches a small, fixed set of Vietnamese running news/knowledge sources once a day (currently: VnExpress's "Thông tin chạy bộ" section, Tuổi Trẻ Online's "marathon" tag page, and VNRUN's public RSS feed) — headline, source, link, publish date, a short snippet, and an image URL only. It never republishes full article text, and every item always links back to the original source as the only way to read the full article.
  • Also fetches a small, fixed set of running-brand storefronts' public category listing pages once a day (currently: PUMA Vietnam's running shoes/apparel/accessories sections, Salomon Vietnam's running shoes/apparel/accessories collections, Li-Ning Vietnam's running shoe collections, and Coolmate's running apparel/accessories collections) — name, brand, category, price (if publicly listed), image URL(s), available color variants, and the brand's own product page link. It also fetches each product's own public page (at most once a week per product) to read a short description, sizes and stock, gender, product code, and the factual specs that page publishes. This is a reference catalog, never a store: it never touches a cart/checkout/payment endpoint, and every item always links back to the brand's own product page as the only way to actually buy it.
  • Sends one request at a time per site, with a multi-second delay between requests, and retries at most once on server errors.
  • Extracts only factual race data: name, date, location, distances, price, and a registration link — never images, articles, or personal data.
  • Never logs in, never touches checkout/registration/payment endpoints, and never bypasses CAPTCHAs or anti-bot protections.
  • Publishes the result as public JSON files at /races/latest.json, /news/latest.json, and /gear/latest.json in this repository, for a companion running/health app to display a merged race calendar, a news feed, and a reference gear catalog.

Source code

This crawler is fully open about what it does — see github.com/NoatToan/unified_health_service for the scraper source code, the data schema, and the GitHub Actions workflow that runs it.

Opt out / contact

If you maintain one of the sites this bot visits and would like it to stop, or crawl less frequently, please open an issue on the GitHub repository above, or add a Disallow rule for UnifiedHealthRaceBot in your robots.txt — it is checked and honored before every run.
